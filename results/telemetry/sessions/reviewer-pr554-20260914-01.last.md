## Review

**F1:** The remote script runs `timeout ... lake build` and propagates its status, including 124. GNU `timeout` also returns 124 when its child exits 124, so the outer wrapper cannot distinguish that build verdict from its own deadline. It converts both to exit 64 and performs a second local build, contrary to the documented rule that only 64 and 65 fall back. Add an exit-124 regression test and preserve distinct transport-timeout and build-timeout statuses.

**F2:** The configured package key matches this checkout today, but PR CI must also handle branches changing `lake-manifest.json` or `lakefile.toml`. The cache protocol defines the package key from the manifest and toolchain, and the build key from the toolchain, manifest, and lakefile. The offload validates only `lean-toolchain` before linking one fixed package tree and an unkeyed seed. A dependency-changing PR can therefore use the wrong checkout or produce an infrastructure failure reported as a proof failure. Validate both keys and fall back with 64 when the remote cache cannot serve them.

**F3:** `cmd_resume` writes `paused = False` before invoking the controller and checking its postconditions. If either operation refuses, the cap files remain paused but the new offload predicate sees an unpaused fast run and returns `yes`. Preserve or restore the paused mode until resume completes successfully. The existing refusal test should also assert that `get offload` remains `no`.

**F4:** On a host explicitly documented as shared, another user can pre-create `/tmp/chsh-setup/known_hosts` before the first install or after cache loss. The installer checks only that it is nonempty, then promotes it to the durable trust store. `StrictHostKeyChecking=yes` subsequently authenticates the injected key, allowing source disclosure and untrusted build artifacts. Bootstrap from an explicit trusted source or verify ownership and a pinned fingerprint.

Static checks passed: `git diff --check`, `bash -n` for the changed shell scripts, and Python AST parsing. The temp-directory unit suite could not be rerun in this read-only reviewer sandbox; the supplied head reports green local CI.
