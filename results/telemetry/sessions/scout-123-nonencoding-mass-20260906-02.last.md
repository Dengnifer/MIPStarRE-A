### Suggested approach

**1. Smallest independent packet: construct the encoding-supported reference measurement.**

For a side and basis \(W\), measure the original Pauli answer \(h\) and the ancillary ideal Pauli answer \(h'\), then return the polynomial \(g_{h+h'}\). Its effects are
\[
N_g^W
=\sum_{\substack{h,h'\\g_{h+h'}=g}}
  M_h^{(\mathrm{Pauli},W)}\otimes\tau_{h'}^W.
\]

Proposed new targets—not existing declarations—are:

- `MIPStarRE.QPBT.poly_eval_agreement_le_mdq`: the real uniform-average specialization of the existing polynomial collision theorem.
- `MIPStarRE.QPBT.ProjectiveSetting.encodedPauliMeas`: the concrete measurement \(N^W\).
- `MIPStarRE.QPBT.ProjectiveSetting.encodedPauliMeas_effect_eq_zero_of_not_isEncoding`: nonencoding outcomes have zero effect.
- `MIPStarRE.QPBT.ProjectiveSetting.encodedPauliMeas_postprocess_eval`: evaluation of \(N^W\) is exactly the blueprint’s convolution
  \[
  K_a^u=\sum_{a'+a''=a}
     M^{(\mathrm{Pauli},W)}_{[g_h(u)=a']}
       \otimes\tau^W_{a''}(\operatorname{ind}_m(u)).
  \]

A natural home is a new, narrowly scoped `MIPStarRE/QPBT/Extraction/EncodingSupport.lean`, with the operator-free collision specialization placed where it can be reused. **This packet requires neither global-witness existence nor the #118 restricted-line law.** Completeness and support require a POVM, not a new projectivity assumption.

**2. Quantitative connection: derive evaluated consistency from the actual checks.**

For Bob’s marginal, use four measurements on the six-register space:
\[
A=\widehat S^W_{[g(u)=a]}\text{ on }BB',\quad
B=\widehat M_A^u\text{ on }AB'',\quad
C=\widehat M_B^u\text{ on }BB',\quad
D=K_A^u\text{ on }AB''.
\]

The three needed estimates are:

- \(A\sim B\): the supplied global-pair witness, with error \(\delta_G\).
- \(C\sim B\): expanded point self-consistency, with error \(c_{\rm pt}\epsilon\).
- \(C\sim D\): the original Pauli-basis check, tensored with the perfectly correlated ideal Pauli measurement and coarse-grained by addition, with error \(c_{\rm pb}\epsilon\).

The existing four-measurement triangle then gives
\[
\operatorname{defect}(A,D)
\le\delta_G+2\sqrt{(c_{\rm pt}+c_{\rm pb})\epsilon}.
\]
Use the other direct placement for Alice. The Pauli-specific tensor/coarse-graining connection is still to be implemented; it is an adaptation of the existing expanded-point construction, not a new assumption.

**3. Recover support mass using the existing codeword comparison.**

Reindex into the actual bipartitions, retaining spectator registers. Compare the global marginal with \(N^W\). Since \(N_g^W=0\) for every nonencoding \(g\), positivity and completeness give
\[
\mathrm{mass}_{\rm nonencoding}
\le \mathrm{full\ polynomial\ inconsistency}
\le \mathrm{evaluated\ inconsistency}+\frac{md}{q}.
\]
Consequently,
\[
\mathrm{mass}_{\rm nonencoding}
\le\delta_G+2\sqrt{c_{\rm pt}+c_{\rm pb}}\sqrt\epsilon+\frac{md}{q},
\]
which has the existing target’s error shape after choosing one universal constant.

**Do not introduce \(d<q\), divide by \(1-md/q\), or require positive \(\epsilon\).** The polynomial collision theorem remains valid when its upper bound exceeds one, and the supplied-witness target includes \(\epsilon=0\).
