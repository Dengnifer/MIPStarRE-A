### Suggested approach
**Proposed new declaration:** `MIPStarRE.QPBT.consistencyDefect_convolution_eq_of_perfect`, naturally in a new `MIPStarRE/QPBT/Games/DistanceTheorems/TensorConsistency.lean`. This name and file are proposals, not existing declarations.

Its precise statement should use a finite additive commutative group \(G\), a finite question type with distribution \(\mu\), four independently typed finite register spaces \(I_A,I_B,J_A,J_B\), and complete POVM families
\[
A_x:G\to\operatorname{Op}(I_A),\quad B_x:G\to\operatorname{Op}(I_B),\quad
R_x:G\to\operatorname{Op}(J_A),\quad T_x:G\to\operatorname{Op}(J_B).
\]
Take \(\psi\in\mathbb C^{I_A\times I_B}\), and \(\phi\in\mathbb C^{J_A\times J_B}\) with \(\|\phi\|=1\). Require ancillary perfect consistency **at each question**:
\[
\sum_{c\ne d}\langle\phi,(R_x^c\otimes T_x^d)\phi\rangle=0.
\]
Define \(\Psi\) using the existing coordinate tensor and shuffle, with the explicit map
\[
((i_A,i_B),(j_A,j_B))\longmapsto((i_A,j_A),(i_B,j_B)),
\qquad
\widehat A_x^z=\sum_{a+c=z}A_x^a\otimes R_x^c,\quad
\widehat B_x^z=\sum_{b+d=z}B_x^b\otimes T_x^d.
\]
The conclusion is
\[
\boxed{\mathcal D_\mu^\Psi(\widehat A,\widehat B)
      =\mathcal D_\mu^\psi(A,B).}
\]
Here \(\mathcal D\) is the existing consistency defect with the two local effect families placed as \(A\otimes1\) and \(1\otimes B\). Thus an input bound \(\mathcal D_\mu^\psi(A,B)\le\delta\) transfers with the **same \(\delta\)**. Original-state normalization and projectivity are unnecessary for this identity.

**Proof on paper.** Set \(p_x(a,b)=\langle\psi,(A_x^a\otimes B_x^b)\psi\rangle\) and \(q_x(c,d)=\langle\phi,(R_x^c\otimes T_x^d)\phi\rangle\). Independence and the specified shuffle factor every joint weight as \(p_x(a,b)q_x(c,d)\). Positivity makes perfect consistency imply \(q_x(c,d)=0\) for \(c\ne d\); completeness and normalization give \(\sum_cq_x(c,c)=1\). Consequently,
\[
\sum_{a,b,c,d}[a+c\ne b+d]p_x(a,b)q_x(c,d)
=\sum_{a\ne b}p_x(a,b)\sum_cq_x(c,c)
=\sum_{a\ne b}p_x(a,b).
\]
Average over \(\mu\). Cancellation is the reason addition gives equality; arbitrary shared coarse-graining gives only an inequality. No uniformity of ancillary answers is required.

**QPBT specialization.** Use the ideal point projectors on the two halves of **the same** EPR pair. Convolving evaluated Pauli answers gives \(K_x^z=\sum_{b+c=z}E_x^b\otimes\tau_x^c\). The needed comparison is expanded point versus \(K\) on `AA'`/`BA''`, or `BB'`/`AB''`, with the unused EPR pair retained as a normalized spectator. Reversing original player order requires explicit coordinate transport, not an assumption that \(\psi\) is swap-invariant.
