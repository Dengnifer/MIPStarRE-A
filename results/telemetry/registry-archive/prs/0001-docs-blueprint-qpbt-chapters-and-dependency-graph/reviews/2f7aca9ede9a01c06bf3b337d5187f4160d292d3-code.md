## Review

Changes are required. Several defects are inherited from the QPBT paper, but the blueprint currently presents them as valid definitions, lemmas, or proofs. Those cases need a policy-compliant local correction and paper-gap verdict rather than silently copying the defect.

F1. The construction in `references/qpbt-paper/04_preliminaries.tex:303-320`, label `def:canonical-complement`, takes pivot columns from reduced row echelon form. Since RREF is unique for a row space, two bases of the same subspace give the same complement. Remove the basis-dependence claims here and at lines 141-142; dependence is only on the subspace and fixed ambient standard basis.

F2. In `references/qpbt-paper/06_nonlocal_games_and_mipstar.tex:94-103`, label `lem:symmetric-strat`, the argument starts with a strategy for every `ε' > ε`. Neither it nor lines 110-122 produce a finite-dimensional strategy attaining `val*`, which line 74 defines as a supremum. State the approximate conclusion or supply an actual attainment theorem.

F3. Primary label `lem:ld-sandwich` at `references/qpbt-paper/06_nonlocal_games_and_mipstar.tex:465-495` contains the same transposition, but the cited `references/neexp-paper/05_quantum_preliminaries.tex:952-973`, label `fact:low-degree-sandwich`, uses `G^k_{g_k}⋯G^1_{g_1}⋯G^k_{g_k}`. The current `G^k_{g_1}` is undefined when the outcome types differ; `k = 0` is also undefined. Apply the documented local correction and handle the empty case.

F4. Source label `def:graph-distribution` at `references/qpbt-paper/07_types.tex:65-82` has the same boundary omission. With no edges, `m = k = 0`, so `1/(2m-k)` is undefined and the displayed mass is not a probability distribution. Require a nonempty edge set.

F5. The paper explicitly permits zero directions at `references/qpbt-paper/08_classical_and_quantum_low_degree_tests.tex:106-116` and samples them at lines 230-237, while its predicate at lines 380-384 asks for “the” `t` satisfying `x=u₀+tv'`. When `v'=0`, every `t` works and a dishonest nonconstant answer gives different values. Specify a canonical zero-direction branch or change and rejustify the distribution.

F6. `references/qpbt-paper/08_classical_and_quantum_low_degree_tests.tex:442-457` prints the same erroneous Reed–Solomon claim. Degree-at-most-`d` evaluation on all `q` points has parameters `[q,d+1,q-d]` when `d<q`, not `[q,d+1,q-d+1]`; for `d≥q`, even the dimension claim fails. Correct the provider argument and split the parameter regimes.

F7. Source `def:admissible` at `references/qpbt-paper/08_classical_and_quantum_low_degree_tests.tex:958-960` requires both an admissible binary field size and `m | q`. Line 235 instead quantifies arbitrary naturals and assumes only divisibility, allowing values for which `F_q` or `tr_{q→2}` is unavailable. Scope the distribution, predicate, and completeness result to an admissible tuple.

F8. Source `def:graph-distribution` assigns equal mass `1/(2m-k)` to every ordered supported pair. Sampling an undirected edge uniformly and then orienting it assigns loops mass `1/m` and oriented nonloops mass `1/(2m)`, which differs whenever loops occur; this graph has a loop at every vertex. Sample uniformly from ordered support.

F9. Source label `lem:delta-bound` at `references/qpbt-paper/08_classical_and_quantum_low_degree_tests.tex:1520-1558` makes the same unsupported comparison. For allowed `a=1`, `b=1/2`, hence `c=4`, and `R=5`, the definitions give `k=9` and `m=8`. Bound `2^{-bm}` directly using `m ≥ (c/2) log R`; the lemma appears salvageable without `k≤m`.

F10. Source `fact:omega-anticomm-prob` at `references/qpbt-paper/14_analysis_of_the_pauli_basis_test.tex:70-92` is inconsistent with the encoding defined at `references/qpbt-paper/04_preliminaries.tex:873-897`. For admissible `(q,m,d)=(2,1,0)`, the actual anticommuting probability is `1/8`, while the second displayed lower bound is `1/2`. Require `d≥1` throughout and replace the false assertion that `ind_m(u)` vanishes exactly at zero.

F11. The source at `references/qpbt-paper/14_analysis_of_the_pauli_basis_test.tex:95-109` concludes only `A≈_δB`; the blueprint adds the exact sentence `‖(A-B)ψ‖²≤δ`. On a singleton distribution, `A=√(2δ)I`, `B=0` satisfies an `O(δ)` premise but violates that exact bound. Retain `O(δ)` or strengthen the hypothesis explicitly.

F12. The public `lem:qld-win-implications` is unrestricted, but its proof establishes the conditional estimates only under `6md≤q` and then appeals to the later `thm:pauli`; the source has the same gap at `references/qpbt-paper/14_analysis_of_the_pauli_basis_test.tex:244-258`. Moreover, `δ_qld≥1` does not trivialize the unsquared norm bound in `thm:pauli`. Prove the unconditional constant mass directly, for example from `ind_m(u)·ind_m(v)=∏ᵢ(1+uᵢ+vᵢ)` in characteristic two.

F13. `def:ld-game` requires its dimension to divide `q`, but lines 898-906 instantiate it with `2m+2`; admissibility only gives `m | q`. For power-of-two `m≥2`, `2m+2=2(m+1)` has an odd factor and cannot divide power-of-two `q`. The same unsupported application occurs at `references/qpbt-paper/14_analysis_of_the_pauli_basis_test.tex:1278-1284`; a soundness theorem with a compatible sampler is required.

F14. Source `references/qpbt-paper/04_preliminaries.tex:917-924` defines `Dec` by replacing non-Boolean cube values with zero. For `q=8`, `m=d=1`, and constant `g=c∉{0,1}`, `Dec(g)=0` while `g(u)=c`. Lines 98-113 and 170-176 use this false identity, so the defect propagates through `lem:qld-construct-the-paulis`, `eq:qld-unitary-6`, `lem:qld-unitary`, and `thm:pauli`.

F15. From `lem:twisted-commutation`, the exact phase is `(-1)^{tr(e_j e_{j'}(u·v))}` for every pair `j,j'`. Self-duality does not make this vanish after multiplication by arbitrary `u·v`. For odd extension degree at least three, take `u=e_j^{-1}` and `v=e_{j'}^{-1}` in one coordinate: the phase is `(-1)^{tr(1)}=-1` even when `j≠j'`. The source claim at `references/qpbt-paper/14_analysis_of_the_pauli_basis_test.tex:1451-1456` is therefore also false.

F16. Source label `lem:qld-unitary` at `references/qpbt-paper/14_analysis_of_the_pauli_basis_test.tex:1765-1783` has the same gap. Without a small-`δ_S` condition, `1-2δ_S-√δ_S` can be negative and the EPR projection can be zero, making `aux₀/‖aux₀‖` undefined. Add a small-error case split and use an arbitrary auxiliary state with a trivial large-error bound in the other branch.

F17. Existing `blueprint/src/chapter/ch03_preliminaries.tex:74-78` and `MIPStarRE/LDT/Preliminaries/Polynomials.lean:25-29` keep polynomial representatives rather than quotienting by evaluation. The new reduced-exponent function presentation identifies, for example, `0` and `X^q-X` when `d≥q`. Preserve the established representation or introduce a separately named evaluation-function object with the necessary restriction.

F18. Property 2 of `lem:qld-sublines` gives each projected point’s marginal separately, while `eq:qld-xz-lines-restricted` assumes a joint product distribution of both line-point pairs. The stronger joint law may follow from the construction, but it is not stated or proved. The source makes the same unsupported inference at `references/qpbt-paper/14_analysis_of_the_pauli_basis_test.tex:1241-1245`; remove this redundant route or prove the joint law.
