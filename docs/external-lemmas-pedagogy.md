# External lemmas — what to reuse and what to prove

**Empty — the project fills this in.** Guidance on when to reach for a result
from the standard library and when to prove a project-local version: which
generalizations are worth the search, which specializations are worth stating
once, and what a "near miss" in the library costs to adapt.

It exists as a file so that the worker personas can link to it from the first
day. Fill it with examples from this project, not with general advice.

Entry shape:

## `<the fact you needed>`

- **In the library?** The name and module, or "no, and here is what I
  searched".
- **Adaptation.** What had to change, and how long it took.
- **Verdict.** Reuse, specialize locally, or prove from scratch — and why.
