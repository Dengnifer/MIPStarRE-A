# Proof hints

**Empty — the project fills this in.** A place for the recurring tactic and
structuring patterns that this particular development keeps needing, written as
short worked examples.

It exists as a file so that `AGENTS.md` and the worker personas can link to it
from the first day. Add an entry when the same difficulty has cost two
different sessions; delete an entry when the library gains a lemma that makes
it unnecessary.

Entry shape:

## `<the difficulty, in the words a session would use>`

- **Symptom.** What the session sees.
- **Why.** One sentence.
- **Pattern.** The smallest example that works, as Lean.
- **Do not.** The attempt that looks right and is not.
