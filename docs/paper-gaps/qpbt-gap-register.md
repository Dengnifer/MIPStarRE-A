# QPBT paper-gap register

This register records every paper-gap note currently known for the quantum
Pauli basis test track. Where a source statement is itself wrong, the blueprint
entry states the corrected mathematics and cites the note. Where the statement
is not known to be false but its printed proof is blocked, the proof-gap
protocol keeps the source-labelled statement as printed and carries the
correction in the proof, in a chapter remark, and -- where the argument does
prove a weaker form -- in a separate formalization-support node. "Open proof"
means that the Lean statement has the indicated shape but its proof still
contains `sorry`.

## Coverage audit

The 2026-09-04 audit checked the QPBT owner-log entries, the live QPBT issue
set, prior blueprint review records, and the repository audits. It recovered
the unmerged linearity-normalization note associated with issue #124 and added
notes for three source corrections that had previously appeared only in Lean
docstrings or blueprint remarks: anticommuting-tuple probability, the binary
Pauli factor index, and the winning implications. The Magic Square rigidity
correction, held at the time of that audit, has since been adopted (owner
decision B5 on #26, packet #172) and is recorded in the table above. No other source-paper discrepancy discussed in
those records lacked a note.

Future QPBT paper-gap packets should add a row here when they add a note and
should update the correction and Lean columns when either layer changes.
