## Coverage audit

The 2026-09-04 audit checked the QPBT owner-log entries, the live QPBT issue
set, prior blueprint review records, and the repository audits. It recovered
the unmerged linearity-normalization note associated with issue #124 and added
notes for four source corrections that had previously appeared only in Lean
docstrings or blueprint remarks: anticommuting-tuple probability, Magic Square
rigidity scope, the binary Pauli factor index, and the winning implications.
No further source-paper discrepancy discussed in those records lacked a note.

Future QPBT paper-gap packets should add a row here when they add a note and
should update the correction and Lean columns when either layer changes.
